# DashboardX Realty Search · самостоятельный поисковый сервер

Виджет ранее умел импортировать внешние ленты, но **не искал объявления сам**.
Этот сервис добавляет ежедневный поиск по индексированным объявлениям Krisha.kz,
OLX.kz и KN.kz для Караганды, без прямого доступа к страницам этих сайтов.

## Как работает

1. Каждые 12 часов сервис формирует поисковые запросы в независимый API DataForSEO
   Google Organic SERP Live Advanced (по умолчанию не более 16 поисков за прогон,
   максимум 32 за сутки). Заданные улицы ротационно меняются парами между
   запусками. Прочие категории: выкуп, часы/сутки, покупка и земля.
2. Из результатов поискового индекса выбирает **только прямые ссылки на карточки
   объявлений** Krisha (/a/show/...), OLX (/d/obyavlenie/...) и KN (/card/...).
   Страницы самих ресурсов **не запрашиваются**.
3. Проверяет, насколько текст похож на объявление, распознаёт цену, улицу, количество
   комнат, площадь и вид недвижимости. Неизвестная цена остается пустой.
   «С выкупом» определяется только при наличии подтверждающих слов в тексте
   результата, а не только поискового запроса.
4. Сохраняет время первой и последней встречи объявления, историю замеченных цен
   и отметку об источнике **поисковый индекс**. **Не утверждает**, что квартира
   доступна сейчас, цена подтверждена или срок публикации точен.
5. Предоставляет совместимую с виджетом JSON-ленту:
   \`GET /api/realty/feed.json\`. Пользователь открывает виджет, который
   читает свежий кэш, а сервер сам обновляет данные по расписанию.
   \`GET /api/realty/status\` и \`GET /health\` — диагностика.
   \`POST /api/realty/refresh\` — только с \`Authorization: Bearer REFRESH_TOKEN\`,
   чтобы никто не мог расходовать платные запросы.

## Railway

Рекомендован **отдельный** сервис, НЕ в API PRO OPTIMA.

- Source: \`blacknode305/dashboardx\`, branch \`main\`
- Root directory: \`/realty-search\`
- Start command: \`node server.mjs\`
- Healthcheck: \`/health\`
- Public domain: railway \`*.up.railway.app\`.
- \`DATAFORSEO_LOGIN\`: логин DataForSEO
- \`DATAFORSEO_PASSWORD\`: пароль API DataForSEO
- \`DATA_DIR=/data\`: подключите **Railway Volume** к \`/data\`, чтобы сохранять
  историю после перезапуска. Если volume не подключён, хранилище эфемерное.
- \`SEARCH_INTERVAL_HOURS=12\`, \`SEARCH_MAX_QUERIES=16\`,
  \`DAILY_QUERY_LIMIT=32\` (по умолчанию).
- \`CORS_ORIGINS=https://blacknode305.github.io\` (разрешён по умолчанию).
- \`REFRESH_TOKEN\`: отдельный случайный секрет для ручного серверного обновления,
  **не помещать в браузерный JavaScript**.

После получения Railway-домена укажите в настройках виджета ссылку вида
\`https://your-service.up.railway.app/api/realty/feed.json\` один раз.

Для повышения качества при необходимости поменяйте шаблоны \`makePlan()\`
в \`search.mjs\`: стоимость запроса увеличивается при наличии операторов \`site:\`.
Ключи никогда не размещайте на GitHub и не отправляйте в обычный чат.

## Стоимость и ограничения

- По состоянию на ноябрь 2026 г. DataForSEO указывает от $0.002 за 10 результатов
  в режиме Live, \`site:\` ×5, то есть ориентировочно $0.01 за запрос.
- 16 запросов × 2 в сутки × 30 дней ≈ 960 запросов / месяц и ≈ $9.60 за API
  при неизменных тарифах, **плюс** стоимость Railway.
- Стоимость реальная зависит от конфигурации/тарифа и других множителей.
- Индекс Google не является полным каталогом объявлений: быстрые публикации
  могут не индексироваться, а старые объявления оставаться в выдаче.
- Krisha.kz запрещает автоматизированный доступ к самому сайту без разрешения:
  https://krisha.kz/content/special/agreement (п. 5.3).
- Использование DataForSEO, её условий и прав на хранение результатов должно
  соответствовать тарифу и применимым договорам; сохранение в данном сервисе —
  ссылки, технические атрибуты и короткие описания результата индекса.
- **Не запускать** второй сервис/автоматизацию, которая параллельно обходит
  те же сайты напрямую.

## Локальная проверка без секретов

\`node --test tests/realty-search.test.js tests/realty-radar.test.js\`

\`cd realty-search && npm start\`

При отсутствии API-ключей \`/health\` ответит \`configuration_required\`, а
JSON-лента будет пустой — это ожидаемый, честный статус. Сервер не выдаёт
демонстрационные объявления за настоящие.
