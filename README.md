# DashboardX — локальная версия (GitHub Pages)

Самостоятельный браузерный DashboardX без Node.js, WebSocket и Webpack.

## Рабочие столы

- В верхнем правом углу — прямоугольные переключатели всех рабочих столов.
- Крестик удаляет выбранный стол после подтверждения. Последний стол можно удалить — вместо него появится новый пустой «Главная».
- Кнопка **+** всегда остаётся последней на панели и создаёт новый пустой стол с единственным системным виджетом управления.
- У каждого рабочего стола всегда есть **один** неудаляемый виджет «Управление виджетами».

## Экземпляры виджетов

- Каждый созданный виджет имеет собственный постоянный ID (например, `datetime-005`).
- Кнопка **Создать** в системном виджете создаёт новый экземпляр с новым ID; несколько экземпляров одного типа могут находиться на одном столе.
- **Показать существующий** добавляет на стол ранее созданный экземпляр с тем же ID.
- Кнопка **На другой стол** показывает этот же экземпляр на другом выбранном рабочем столе.
- Кнопка **Копия** создаёт независимый экземпляр с новым ID.
- **Убрать** снимает экземпляр только с текущего стола. Если он нигде больше не используется, его определение удаляется.
- Положение и размеры хранятся отдельно для каждого сочетания «стол + ID».
- Финансовые виджеты в этой версии используют **общий финансовый журнал**, даже если их ID отличаются: отдельные кошельки по ID ещё не реализованы.

Все настройки живут в `localStorage` текущего браузера. **Очистить localStorage** сбрасывает только данные DashboardX (не хранилища других приложений того же домена) после подтверждения.

## Опубликовать на GitHub Pages

Открой **Settings → Pages**, выбери **Deploy from a branch** → `feature/dashboardx-local` → `/(root)` → Save.

Адрес после успешной публикации: https://blacknode305.github.io/dashboardx/

`.nojekyll` нужен для публикации файлов шаблонов `client/_*.html`.

## Локальная разработка

Для работы ES-модулей в браузере нужен статический HTTP-сервер, например `python3 -m http.server 8000` из корня репозитория, после чего открыть `http://localhost:8000/`. Отдельный сервер приложения не требуется.

## Ограничения и безопасность

Telegram, серверная консоль и серверный аудиоплеер в локальном режиме отключены. Binance и валютные курсы зависят от внешних API и доступности интернета. localStorage не синхронизируется между устройствами и не является шифрованным хранилищем.

Ранее опубликованные секреты и персональные данные по-прежнему могут находиться в старых ветках и истории Git; их необходимо отдельно отозвать и удалить из публичной истории.
