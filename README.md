# DashboardX — GitHub Pages, без сборщика и сервера

Версия `feature/dashboardx-local` — статическое веб-приложение на HTML, CSS и нативных JavaScript-модулях, без Webpack, Node.js и WebSocket.

## При первом запуске

- `localStorage` **не заполняется автоматически**.
- На единственном рабочем столе «Главная» показан только системный виджет **«Добавить виджет»**.
- Ни демонстрационных виджетов, ни финансовых транзакций не создаётся.
- **Ваши собственные** изменения сохраняются и восстанавливаются после перезагрузки страницы; при каждом обновлении их не стирают.
- Сохранённые данные предыдущей версии v2 продолжают открываться. Автоматического импорта старых демонстрационных виджетов и старых финансовых ключей больше нет.
- Для ручного сброса используется кнопка **«Очистить localStorage»**, очищающая данные DashboardX, но не посторонних сайтов/приложений на том же домене.

## Рабочие столы

Прямоугольные вкладки столов расположены справа в верхней панели. У каждой вкладки есть крестик для удаления с подтверждением; после последней вкладки всегда расположена кнопка **+**. При удалении всех столов создаётся пустая «Главная». Длинные названия должны переноситься внутри расширяющейся вкладки.

На каждом столе всегда присутствует один неудаляемый системный виджет управления.

## Выбор виджетов

В системном виджете две раскрывающиеся панели:

1. **Новый экземпляр** — выберите тип виджета и нажмите **Добавить**. Каждый экземпляр получает новый уникальный ID. На одном столе могут находиться несколько виджетов одного типа.
2. **Существующий экземпляр** — выберите ID и нажмите **Показать**. Один экземпляр можно отображать на нескольких рабочих столах.

На каждом столе отображается список уже размещённых экземпляров, с действиями **Копия**, **На другой стол** и **Убрать**. Копия имеет независимый ID, а размещённый на другом столе тот же ID остаётся тем же экземпляром. Положение и размер сохраняются отдельно для каждого стола.

Раскрывающиеся панели используют нативный элемент HTML `details` с доступными кнопками выбора; списки остаются работоспособными при ограниченной высоте виджета. Если одна необязательная HTML-заготовка недоступна, остальные виджеты продолжают загружаться.

## Публикация

Откройте **Settings → Pages**: **Deploy from a branch** → `feature/dashboardx-local` → `/(root)` → Save.

Адрес сайта после успешного развёртывания: https://blacknode305.github.io/dashboardx/

Файл `.nojekyll` обязателен: имена исходных HTML-шаблонов начинаются с подчёркивания.

## Локальный запуск и ограничения

Откройте из корня проекта любой статический HTTP-сервер, например `python3 -m http.server 8000`, затем `http://localhost:8000/`. Это исключительно раздача файлов; отдельный сервер приложения не нужен.

Финансовые виджеты пока используют **общий финансовый журнал**, даже если у них разные ID. Виджеты Telegram, серверной консоли и серверного аудиоплеера отключены. Внешние котировки могут требовать интернет. Данные в `localStorage` не шифруются и не синхронизируются между устройствами.

**Осторожно:** ранее опубликованные секреты и персональные данные могут оставаться в старых ветках и истории GitHub. Их нужно отдельно отозвать и удалить из истории.
