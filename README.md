# DashboardX — автономная версия для GitHub Pages

Ветка: `feature/dashboardx-local`.

DashboardX работает как обычная статическая страница, без Webpack, Node.js и WebSocket.
Данные сохраняются только в `localStorage` браузера.

## Интерфейс

- **Окна виджетов:** кнопки сохранения, показа на другом столе, избранного, закрепления, скрытия, разворачивания и закрытия находятся в верхнем заголовке. Нижней панели управления больше нет.
- **Размеры:** тяните за маленький угол внизу справа. Положение и размеры каждого окна сохраняются отдельно для сочетания «рабочий стол + ID экземпляра».
- **Виджет добавления:** один неудаляемый на каждом рабочем столе. Внутри два раскрывающихся меню — создание нового экземпляра или показ существующего по ID.
- **Рабочие столы:** прямоугольные вкладки справа сверху, отдельный красный крестик удаления и постоянная кнопка `+`. Длинные названия переносятся внутри вкладок.
- **Языки:** переключатель RU / KZ / EN в верхней панели. Язык интерфейса, элементов управления виджетов и дат настраивается и сохраняется локально.
- **Темы:** тёмная и светлая с общими CSS-переменными.
- **Фон:** кнопка «Фон» запрашивает ссылку на изображение. Каждому столу можно назначить свой фон. Пустая строка сбрасывает фон. На GitHub Pages используйте **HTTPS**-ссылки на картинки.
- **Очистка:** кнопка рядом с названием DashboardX сбрасывает данные этого приложения после подтверждения.

## CSS

Единственная точка подключения общих стилей — `client/css/style.css`. В ней находятся CSS-переменные двух цветовых схем, оформление окон, шапки, вкладок и менеджера. Существующие небольшие CSS-файлы внутреннего содержимого отдельных виджетов подключаются через `@import` для сохранения совместимости. Старые дублировавшие общий стиль файлы исключены из ветки.

## Данные

В новом браузере автоматически появляется только пустой стол «Главная» и системный виджет добавления. Начальный `localStorage` пустой: никаких демонстрационных виджетов, финансов или изображений туда не записывается.

После выбора языка, создания или изменения виджетов и других явных действий пользователя настройки сохраняются между перезагрузками. Изменения одной копии виджета с отдельным ID не влияют на другой экземпляр, но финансовые виджеты пока используют общий финансовый журнал.

## Публикация

GitHub → **Settings → Pages → Build and deployment → Deploy from a branch**.
Выберите `feature/dashboardx-local`, папку `/(root)`, затем **Save**.

Ожидаемый адрес после успешной публикации: https://blacknode305.github.io/dashboardx/

`.nojekyll` сохраняется для публикации HTML-шаблонов с именами, начинающимися с подчёркивания.

## Локальный просмотр

Откройте статический HTTP-сервер в корне репозитория, например
`python3 -m http.server 8000`, и перейдите на http://localhost:8000/.
Запуск через `file://` не гарантирован, потому что приложение использует ES-модули и `fetch()` для HTML-шаблонов.

## Ограничения и конфиденциальность

Виджеты Telegram, серверной консоли и серверного аудиоплеера здесь отключены.
Binance и внешние курсы валют могут не работать без интернета или при ограничениях API.
`localStorage` не шифрует данные и не синхронизирует их между устройствами.
Старые секреты и персональные данные могут оставаться в истории и других ветках GitHub — их нужно отдельно заменить и очистить историю.
