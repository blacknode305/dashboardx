# DashboardX — GitHub Pages / localStorage

Ветка `feature/dashboardx-local`: статический HTML/CSS/JavaScript, без Webpack и обязательного сервера.

## Виджеты

**Все 16 исходных типов**, включая системный `add`, явно зарегистрированы в объекте `WIDGET_CATALOG` внутри `client/js/index.js`. Категории оригинальных шаблонов: `system`, `finance`, `tools`, `media`, `games`, `telegram`. Названия категорий отображаются ЗАГЛАВНЫМИ.

Список в постоянном системном виджете «Добавить виджет» берётся из реестра, **а не из результатов загрузки HTML**. Неудачная загрузка отдельного шаблона не удаляет тип из списка: при добавлении отображается сообщение о недоступном шаблоне.

Серверные типы `serverConsole`, `telegramBot` и `audioPlayer` присутствуют в каталоге, но в автономном режиме показывают заглушку о необходимости сервера. Остальные использованные виджеты получают прежние шаблоны и JS-логику.

Каждый пользовательский экземпляр имеет уникальный ID. Существующие экземпляры можно показать на другом рабочем столе; копирование создаёт новый независимый ID. Начальная страница не создаёт демонстрационных экземпляров или транзакций.

## Рабочее пространство

- **Новый фирменный фон** из `client/src/dashboardx-wallpaper.svg`, закреплённый и неподвижный при прокрутке.
- Настроенный пользователем фон через кнопку **«Фон»** сохраняется отдельно для текущего рабочего стола.
- Верхняя панель и панель категорий **закреплены** и не прокручиваются.
- Рабочая область — отдельный прокручиваемый холст с началом координат (0,0). Виджеты не могут перемещаться выше или левее начала: расширение холста возможно **только вниз и вправо**. У верхнего края разрешена прокрутка только до уже существующего начала, без создания дополнительного пространства. Ранее сохранённые отрицательные координаты приводятся к нулю при открытии.
- Кнопка **«Полный экран»** использует браузерный Fullscreen API; некоторые браузеры могут его ограничивать.
- Размер виджета изменяется нижним правым углом; управление находится в заголовке.
- Меню типов сгруппировано по категориям, подписи и кнопки адаптируются к ширине окна и не должны выходить за рамки.
- Сохранился выбор RU / KZ / EN и переключение светлой/тёмной темы. Общие стили и цветовые схемы находятся в `client/css/style.css`.

## Горячие клавиши

- **D + Alt + Tab**: удерживайте D и Alt и нажимайте Tab, чтобы переключаться по созданным рабочим столам по кругу, не перезагружая страницу.
- **D + Alt + Shift + Tab**: в обратном направлении.
- **D + Alt + → / ←**: альтернативный способ, когда Alt + Tab перехватывается операционной системой и не доходит до браузера.

Сочетания работают, только пока страница получает события клавиатуры. В Windows и некоторых окружениях **Alt + Tab** всегда переключает системные окна, и сайт не может отменить это поведение.

`feature/dashboardx-local`, папка `/(root)`.

Адрес после успешной публикации: https://blacknode305.github.io/dashboardx/

`.nojekyll` позволяет публиковать оригинальные файлы шаблонов, начинающиеся с `_`.

Для локального просмотра нужен лишь статический HTTP-сервер из корня репозитория, например `python3 -m http.server 8000`. Откройте `http://localhost:8000/`; не используйте `file://` для модулей и `fetch()`.

## Данные и ограничения

`localStorage` сохраняет изменения, но не синхронизирует устройства и не шифрует содержимое. Очистка данных DashboardX требует подтверждения. Старые секреты и персональные данные могут оставаться в других ветках и истории Git и должны быть отозваны/очищены отдельно.

## Внутреннее состояние виджета «Курсы валют»

Виджет `moneyConvertApi` больше не отображает заранее заданные строки KZT, RUB, ETH.
При первой настройке список пар **пустой** — старые курсы и настройки из прежнего виджета не импортируются. Существующие рабочие столы, другие виджеты и финансовые операции не удаляются.

1. В первом поле выберите **исходную валюту** через поиск по началу кода или названия, например `US` → `USD`.
2. Во втором выберите валюту **назначения**, например `KZ` → `KZT`.
3. Нажмите «Добавить пару». Ниже появится курс `1 USD = ... KZT`, рассчитанный по MoneyConvert.
4. Добавляйте дополнительные пары и удаляйте ненужные крестиком. Повторное добавление одной и той же направленной пары запрещено.

Список доступных валют подгружается из <https://www.moneyconvert.net/api/>; API возвращает котировки всех валют относительно USD. Значение `FROM → TO` равно `rates[TO] / rates[FROM]`, обновление — примерно раз в пять минут.

**Где хранится память:** `localStorage["dashboardx.local.v1"].instances[instanceId].widgetState.pairs`, например `[{"from":"USD","to":"KZT"}]`. Числовые котировки **не сохраняются**: они загружаются заново. У разных ID собственные списки пар. Если один и тот же ID показан на двух столах — настройки общие, при создании новой копии они пустые. Старый глобальный кеш `rate` очищается без удаления остальных данных.

Если MoneyConvert недоступен, виджет явно сообщает об ошибке. Уже сохранённые пары остаются на месте, но вместо неподтверждённого курса отображается сообщение об отсутствии значения.


## Правило проекта — API-токены и секреты

**Для будущих виджетов:** пользователь вручную вводит Telegram API Token и другие приватные ключи в отдельные виджеты настроек. Не прописывать секреты в исходном коде, GitHub, `.env.example`, URL картинок, общедоступных HTML-файлах, логах или теле `localStorage`.

В текущем статическом GitHub Pages приложение невозможно сделать полноценным безопасным хранилищем секретов. Виджет `telegramSettings` принимает `Token TelegramApi` в поле `type=password` и хранит его **только в памяти текущей вкладки**, пока она открыта; после перезагрузки требуется вводить снова. Токен не отправляется в Telegram API из браузера. Для будущей авторизованной работы с Telegram понадобится отдельный защищённый сервер-посредник. После удаления экземпляра токен из памяти очищается, даже если его ID будет использован вновь.

## ID виджетов и переходы

Каждый тип нумеруется независимо с `000`: `moneyConvertApi-000`, `moneyConvertApi-001`, `moneyConvertApi-002`. После **полного** удаления `002` со всех столов следующий экземпляр получает `002`, если все более ранние ID этого типа заняты. Если экземпляр остаётся на другом рабочем столе, его ID занят. Существующие ID автоматически не переименовываются, чтобы не потерять настройки.

Клики на вкладки рабочих столов, создание и удаление столов, добавление, копирование и удаление виджетов теперь обновляют интерфейс без `location.reload()`; те же функции используются сочетанием `D + Alt + Tab`. Полный сброс локального хранилища, напротив, перезапускает страницу для очистки памяти приложения.

Использована **настоящая часть второго сгенерированного изображения**: `client/src/dashboardx-second-mockup-nebula.jpg` — небольшой фрагмент центрального космического неба без нарисованных виджетов. ## Urban-тема и ограничения холста (2026-10-24)

Оформление `client/css/style.css` переведено из неонового glass UI в сдержанный **Urban**: матовый графит, серо-стальные границы, спокойные голубовато-серые акценты, приглушённые зелёные и терракотовые финансовые действия. Убраны дополнительное сияние второго макета, разноцветные переливы, яркие градиенты и размытие карточек. Шапка и расположение элементов остаются прежними. Фирменный фон DashboardX оставлен, но затемнён; пользовательский фон по URL не изменяется.

Перемещение больше не расширяет холст вверх, а сохранённые координаты виджетов выше или левее нуля исправляются при открытии. Вниз и вправо виджеты можно перемещать за границы текущего окна, прокручивая холст. Данные, созданные виджеты, валютные пары и локальные настройки не сбрасываются.

## Наведение и фокус кнопок (Urban)

Общие переменные `--dx-hover-*` в `client/css/style.css` управляют матовыми состояниями наведения для шапки, RU/KZ/EN, рабочих столов, панели категорий, заголовков окон и команд виджетов (менеджер, финансы, Telegram, калькулятор). Опасные действия выделяются приглушённым красным. При управлении клавиатурой виден `:focus-visible`. Размеры элементов при наведении не меняются, отключённые кнопки не подсвечиваются. Логика виджетов и `localStorage` не изменены.

## Наведение «Полный экран» / «Фон» и прозрачность рабочего стола

Для `#fullscreen-toggle` и `#background-button` заданы собственные `:hover:not(:disabled)` и `:focus-visible`: их высокий CSS-приоритет перекрывает стили обычного состояния, но не изменяет размеры кнопок. Сохраняется матовый Urban-стиль. Фирменные обои теперь меньше затемняются в тёмной теме (слои прозрачности 0.56/0.68 вместо 0.69/0.81) и меньше осветляются в светлой (0.70/0.77 вместо 0.83/0.90). Для пользовательских обоев затемнение снижено до 0.13/0.18 вместо 0.20/0.25. Поведение рабочих столов, виджетов и внутренней памяти не изменено.
